# Hinted cubic diagonal executable acceptance

This directory is generated by:

```bash
python3 tools/export_hard_cubic_householder.py \
  --task QBE-HARD-CUBIC-DIAGONAL-HIER-HINTED-001 --n 2
```

The finite export checks both Lean roots: the exact linear input
`O_0 = diag(j / 2^n)` and the exact cubic diagonal output.  It also checks
`diag(x)^3 = diag(x^3)` for the finite grid.  QSVT is an optional optimized
consumer, not an assumed local proof.  `qiskit/acceptance.json` and the two
parsed QASM3 files are finite post-Lean artifacts; they do not replace the
symbolic Lean certificates.
