The following remain obligations: \(\ODBS\) injectivity and dagger cleanup,
\(\ODT\) coefficient-normalizer and rotation unitarity,
boundary-rotation analytic identities, \(\Uf\) nonzero \(N_f\), division
semantics, normalizer bound, orthogonal completion, theorem-level amplitude
correctness, unitary completion, and final block extraction with normalizer
\(N_DN_f\kappa\).  The circuit-claim and target-level block flags are both
explicitly false.  The current active \(\ODBS\) source domain is
\Lean{bandedSparseAccessPaperGlobalSlotSource};
\Lean{QBE.ODBS.UnusedZeroBranchExtension} is retained only as rejected-model
memory for the old row-dependent helper.

The latest \(\ODBS\) guards are regression checks, not semantic closure.
Source column \(8\) separates the active Lemma 1 paper-image matrix from the
legacy helper, while source columns \(0\) and \(48\) now witness the rejected
row-dependent collision and the corrected active global-slot separation.  The guard
\Lean{oneTermRobinBlockEncodingProofRoute\_sourceDecisionOnlyFreeze\_n3}
packages these facts with the empty unused-branch image slot and the false
theorem flags.  The newer guard
\Lean{oneTermRobinBlockEncodingProofRoute\_sourceDecisionWrapperSlotsBlocked\_n3}
adds the wrapper-level check for the same column \(48\): both the direct
image-rule contract and the full clean-domain wrapper still have
\Lean{proposedImageIndex = none}.
The guard
\Lean{oneTermRobinBlockEncodingProofRoute\_gateListAndFlags} also pins the
active matrix order to \Lean{oneTermRobinCircuit}, so future source-contract
packets cannot silently reorder the seven gates while preserving the same
false-flag vector.
