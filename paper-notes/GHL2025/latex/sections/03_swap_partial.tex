\section{SWAP Partial Blocks}

Let
\[
  \operatorname{mask}=2^n-1.
\]
For a basis index \(j\), define
\[
  b_1(j)=(j\gg1)\mathbin{\&}\operatorname{mask},
  \qquad
  b_2(j)=(j\gg(1+n))\mathbin{\&}\operatorname{mask},
\]
and
\[
  d(j)=b_1(j)\oplus b_2(j).
\]
The SWAP image is
\[
  S(j)=j\oplus(d(j)\ll1)\oplus(d(j)\ll(1+n)).
\]

Lean proves that \(d(j)<2^n\), as
\Lean{swapOracleDiff\_lt\_two\_pow}.  Hence
\[
  d(j)\gg n=0
\]
and
\[
  (d(j)\ll n)\mathbin{\&}(2^n-1)=0,
\]
recorded by \Lean{swapOracleDiff\_shiftRight\_eq\_zero} and
\Lean{swapOracleDiff\_shiftLeft\_mask\_eq\_zero}.

Using these facts, Lean proves the first register identity:
\[
  b_1(S(j))=b_2(j).
\]
This is \Lean{swapOracleImage\_block1\_eq\_block2}.

The symmetric identity \(b_2(S(j))=b_1(j)\), the self-inverse theorem, the
bijection theorem, and SWAP unitarity remain obligations.
