# ABEIS Unified Formalization Website

This directory is the build layer that unifies the existing ABEIS task builder,
Lean Library Explorer, and Verso Blueprint. It does not define a second
declaration inventory.

## Inputs

- `QuantumBlockEncoding/**/*.lean`: authoritative declarations and source lines.
- `web/library/declarations.json`: deterministic inventory generated by
  `scripts/generate-blueprint-catalog.py`.
- `docs/blueprint-coverage.json`: generated coverage and exclusion audit.
- `ABEISBlueprint/`: Verso chapters and strictly resolved declaration panels.
- `website/content.py`: curated teaching order and broader route statuses.
- `website/diagrams/*.mmd`: editable ABEIS-specific diagrams.

Every declaration name in `content.py` is checked against the generated
inventory before HTML is written.

The Pages build passes `--without-preview-data` to `ABEISBlueprintMain.lean`.
This retains multi-page HTML, strict declaration resolution, xref data, search,
and the Blueprint/Modern/Bold styles while avoiding a second full traversal
that renders hover-cache fragments for every declaration. Running
`ABEISBlueprintMain.lean` without that flag still produces the complete Verso
preview cache when a downstream consumer explicitly needs it.

## Outputs

`website/scripts/build_site.py` writes `_out/site/`. `scripts/build-website.sh`
then assembles that output with `_out/blueprint/` into `_site/`, preserving:

- `library/`;
- `blueprint/html-multi/`;
- the task builder at `task-builder/`.

Build-time evidence is available in `_site/build-report.json`. The final
declaration inventory, including publication-safe source links, is at
`_site/library/declarations.json`.

## Status Rules

- `Compiled` is published only when `_out/lean-gate.json` certifies the current
  commit after `lake build` and `lake build Tests`.
- A compiled structure may still have `Partial route` status when concrete
  proof fields or an external algorithmic stage remain.
- The optional `RobinMatrix.lean` module is `Experimental`; declarations with
  an actual `sorry` term are `Stated, proof incomplete` and `Blocked`.
- Paper contracts, oracle assumptions, QSVT consumer interfaces, candidate
  costs, and harness policies keep their local and broader-route statuses
  separate.

## Source Links

Tracked inventory files never assume the `main` branch. During publication,
the builder reads `origin`, `HEAD`, and remote branch containment. A GitHub
link is emitted only when the source file is clean and exists at that commit.
Otherwise readers use the stable local module/declaration anchor.

## Commands

Run the complete build and acceptance suite:

```bash
bash scripts/build-all.sh
```

After `_site/` exists, start an authenticated temporary preview:

```bash
python3 website/scripts/serve_preview.py --root _site
```

The preview username and password must be supplied through
`ABEIS_PREVIEW_USERNAME` and `ABEIS_PREVIEW_PASSWORD`.
