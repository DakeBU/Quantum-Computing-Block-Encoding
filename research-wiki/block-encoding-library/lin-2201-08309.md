# Lin 2201.08309 Memory Pack

Source: Lin Lin, "Lecture Notes on Quantum Algorithms for Scientific
Computation", arXiv:2201.08309.

ABEIS uses this note as a textbook-style route library for block-encoding
construction.  The main asset is not one theorem, but a proof habit:

```text
block encoding
-> clean basis entry
-> finite circuit action or inner product
-> target matrix entry divided by alpha
```

In Lean-facing form, most exact proofs should try to reduce to:

```lean
forall row col,
  U (cleanIndex row) (cleanIndex col) = A row col / alpha
```

## Backbone Map

Lin 2201.08309 is used as the first "graduate textbook" backbone for ABEIS:
it teaches agents the canonical clean-block proof shape before they try
paper-specific constructions.

```text
Definition of BE
  -> entrywise clean-block verification
  -> value oracle to amplitude oracle
  -> one-sparse support/permutation route
  -> sparse column and row-column access routes
  -> contraction/SVD dilation fallback
  -> LCU PREPARE--SELECT arithmetic
  -> Hermitian block encoding and qubitization consumers
  -> QSVT consumer contract
```

The arrows are proof dependencies, not just topic order.  For example,
one-sparse and sparse-access proofs both reuse Kronecker-delta entry
collapse; LCU and product rules consume already-extracted clean blocks; QSVT
must consume a proved block encoding rather than replacing the original oracle
construction.

## Intuition Library

| Technique | Intuition for agents | Proof object to produce |
| --- | --- | --- |
| entrywise clean block | a block encoding is just the clean-ancilla matrix entries | `forall row col, cleanEntry = target/alpha` |
| partial permutation | put the desired basis action in the clean branch and send all other clean inputs to dirty branches | finite image theorem plus clean projection |
| one-sparse | amplitude supplies the value and a permutation supplies the only possible support row | delta support collapse |
| sparse access | location oracles turn the entry into a finite sum with Kronecker deltas | slot-sum or double-delta contraction |
| value-to-amplitude | compute a value, rotate a signal qubit, then uncompute garbage | cleanup proof plus amplitude equality |
| LCU | PREPARE amplitudes and SELECT terms interfere in the clean postselection branch | coefficient normalization and finite weighted sum |
| dilation | a contraction becomes unitary by storing the missing norm in an orthogonal branch | 2-by-2 row/column orthogonality |
| qubitization/QSVT | transform a spectrum or singular values after the input BE exists | downstream contract with side conditions |

## Normalizer, Error, and Ancilla Flow

For each route, upper and middle agents should record:

- `alpha`: sparsity count, coefficient one-norm, value bound, contraction
  scale, or inherited normalizer;
- `a`: signal qubits, index/preparation registers, and pure workspace that
  must return to zero;
- `epsilon`: exact `0`, approximation from arithmetic/rotation/QSVT, or
  task-level relaxed tier;
- cleanup: which workspace registers are uncomputed before the clean
  projection;
- reusable leaf: the smallest compiled theorem that can discharge the next
  proof-DAG node.

This prevents a common failure: saying "the oracle exists" when the proof
actually needs a value oracle, a location oracle, a controlled rotation, and a
cleanup theorem.

## Route Selector Update

- Matrix unit or partial reset: use partial permutation first.
- One nonzero per column/row: use one-sparse permutation/amplitude card.
- Sparse access with location oracles: use column or row-column sparse cards.
- Dense contraction fallback: use scalar or SVD dilation only when no better
  structure is available.
- Polynomial transforms: use QSVT only after a BE certificate exists.

## Current Formalization Boundary

Compiled Lean leaves currently cover entrywise clean blocks, product-register
clean blocks, one-sparse reconstruction, sparse-column no-hit and unique-hit
slot collapse, scalar dilation entries and row orthogonality identities,
Chebyshev recurrence values, proof-carrying sparse/value/QSVT contracts,
two-term LCU arithmetic, and exact certificates as zero-error approximate
incumbents.

Open leaves are intentionally explicit:

- full row-column sparse delta contraction;
- full PREPARE-SELECT-PREPARE dagger algebra;
- diagonal/SVD dilation unitarity over a richer numeric backend;
- QSP/QSVT phase admissibility and global polynomial theorem.
