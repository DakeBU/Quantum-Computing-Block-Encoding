# Guseynov-Huang-Liu 2025 Contribution Memory

This directory tracks the first ABEIS paper-benchmark case:
Guseynov--Huang--Liu 2025.  The generated `index.md`, `source-map.md`, and
`todo.md` files are refreshed from the source-anchor table, proof obligations,
trial logs, verifier feedback, and Lean `sorry` scan.  The benchmark fixes the
paper's construction; any search for a smaller auxiliary register, lower depth,
or fewer gates must be recorded as a separate operator-construction or
improvement task with the same target operator.
