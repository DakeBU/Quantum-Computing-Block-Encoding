The O_D^BS blocker from the current row-dependent Lean model is reclassified.
The compiled collision witness remains useful, but it is a rejected-model
regression test, not a paper-level source gap.

The faithful source interpretation is:

- GHL2025 Lemma `Diagonal sparsity` and Lemma `Banded-sparse-access-oracle`
  use a global band/diagonal slot $s$ with
  $r_{si}=r_{s0}+i \bmod 2^n$.
- Remark `sparsity maximum` says the Robin heat example has $\kappa=7$
  diagonal slots, including boundary-effect diagonals.
- The one-term Robin paragraph before Theorem `1 term robin` says zeros can be
  included and then uses the full range $s=0,\dots,\kappa-1$.

coefficients in the amplitude layer, while the sparse-access index oracle keeps
the global slot.  The active address and source-domain transcript now use
`oneTermRobinGlobalSparseAddress` and
`bandedSparseAccessPaperGlobalSlotSource`.  Historical notes below that named
`QBE.ODBS.UnusedZeroBranchExtension` as the active blocker are superseded:
that row is retained only as rejected-model memory for the old row-dependent
helper.  The current proof blockers are the corrected global-source
permutation, inverse-on-range, dagger cleanup, unitarity, and final block
extraction obligations.
