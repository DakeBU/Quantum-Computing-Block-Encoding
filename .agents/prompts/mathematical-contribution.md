# ASPBE contributor packet

Read AGENTS.md, HARNESS.md and docs/theorem-publication-protocol.md first.
Use `python3 website/scripts/research_atlas.py context --route ROUTE_ID` or a
bounded structure query. Keep the exact source statement, input/oracle model,
register and phase conventions, norm, ancilla cleanup, success and cost tier.

Own one substantive mathematical frontier objective end to end. Search local
ASPBE and Mathlib before creating parallel definitions. Cite external results
without pretending a source reference is a compiled Lean import. Preserve prior
art, including the existing function-to-MPS and sequential preparation routes.

Author the mathematical statement and full proof once. Display all relevant
hypotheses and exact source-to-Lean differences. Provide separate initially
folded exact Lean statement and proof. Connect each source obligation to its
actual local declarations and distinguish prerequisite from proof-edge.

For every changed production module, make a current publication packet with
whole-module/toolchain/manifest/source/lesson hashes, all public declarations,
assumption deltas, and a pinned graph contribution. Obtain a genuinely distinct
source-blind decoder and anti-anchored reviewer; never invent their identity,
run or verdict. A source repair is a separately reviewed proposal, not an edit
that overwrites the original. Unchanged historical debt remains debt.

Show graph changes as add-node, shortcut, reorganisation or bridge with the same
node identities as the generated Lean graph. Retain whole AND tails and explicit
hypothesis, conclusion and failure maps. A conceptual bridge is not a verified
functor, and a module import is not an elaborated theorem dependency.

Run focused checks during editing and integrated gates on the merge candidate:
research schema/unit tests, publication diff gate, Lean/library/tests, full site,
links/fragments, source provenance, MathJax and responsive browser checks. Do not
weakly skip missing files or create green placeholder evidence.

Return: exact objective/delta; named Lean and source evidence; reused nodes;
assumption and resource differences; independent review artifacts; graph delta;
actual test commit/results; remaining global boundary; next bounded advance.
Stop after repeated unchanged failure with a typed obstruction rather than
continuing activity without advancing the target.
