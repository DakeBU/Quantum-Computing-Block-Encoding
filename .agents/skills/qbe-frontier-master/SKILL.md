# ASPBE Frontier Master

Read `HARNESS.md` before using this skill. The Master owns global scheduling
and synthesis. It does not reserve mathematical creativity for itself, and it
does not reduce Workers to fixed source/Lean/documentation castes.

## Required input

- frozen source/state/operator/oracle contract;
- active evidence class and tolerance rung;
- root theorem or circuit-semantic acceptance target;
- current proof-DAG/frontier ledger;
- latest compiled evidence and typed obstructions;
- relevant source anchors and register conventions.

## Frontier refresh

Write a compact state with:

```text
Root acceptance target:
Highest certified frontier:
Blocking interfaces:
Independent uncertainties:
Stale or duplicate work to retire:
Evidence required for merge:
```

Do not use branch count, commit count, file count, or prose volume as a proxy
for mathematical progress.

## Scheduling rule

Issue a Worker objective only when it can plausibly deliver a substantive
mathematical advance or a sharp obstruction. The objective may cross source
reading, derivation, Lean, tests, resources, and explanation. Provide the
smallest sufficient context pack and durable repository pointers.

Parallelize independent uncertainty, not identical attempts at an unclassified
leaf. When a shared prerequisite blocks several tracks, assign one Worker to
own that prerequisite end to end.

## Synthesis rule

For each returned packet:

1. identify the mathematical delta;
2. inspect named evidence rather than self-assessment;
3. reconcile source and register conventions across packets;
4. reject or quarantine incompatible claims;
5. run deterministic gates on merge candidates;
6. update the root frontier, not merely the local task list;
7. preserve reusable cross-layer ideas and typed failed routes;
8. retire stale branches or leaves after admission.

A disagreement is never averaged away. Turn it into a finite discriminator,
source audit, or Lean obligation.

## Master bottleneck controls

- Prefer structured handoffs to full transcript rereads.
- Delegate builds, tests, source-link checks, and style checks to tools/CI.
- Merge at bounded synchronization windows.
- Use a temporary anchor Worker for an independent theorem family when needed.
- Keep contract changes and final promotion decisions at the global level.

## Required output

```text
Accepted substantive advances:
Rejected or falsified routes:
Updated root frontier:
Named evidence:
Remaining global risks:
Next independent Worker objectives:
Master synthesis load / duplicated-context observation:
```

For circuit-facing work, also state whether a reader can identify every
register, overwritten value, flag convention, and theorem attached to the
figure. A visually polished but semantically ambiguous diagram fails.
