# QBench-Informed Semantic Bridge Experiment

Experiment date: 2026-07-29 JST

## Fixed question

Can two failure-derived, independently proved semantic adapters turn repeated
representation reconstruction into named Lean prerequisites without widening
the ABEIS trust boundary?

This is a source/build experiment, not an agent solve-rate benchmark.  No new
proof-agent session was launched, so no token, throughput, or wall-time
causality is claimed.

  `signalSystemBlockProjection`, and `cleanBlockProduct`;

The historical token figure is a local prompt-size proxy, not provider billing.

## Intervention

`QuantumBlockEncoding/ConcreteSemantics.lean` adds:

1. finite `basisKet`, `zeroKet`, and Mathlib `mulVec` action;
2. `firstColumnMatches_iff_applyVec_zeroKet`;
3. a complex certificate whose gate must satisfy Mathlib
   `Matrix.unitaryGroup`;
4. flat/product register views and clean-block projection equivalences.

The technical-lemma registry promotes seven declarations only after source,
signature, status, attribution, and local build checks.

The harness separately classifies `symbolic_bridge_gap`,
`shape_or_register_gap`, and `source_translation_gap` as structural
prerequisites.  Such feedback freezes lower workers, capacity growth, and
epsilon relaxation.  One unchanged prerequisite pass stops instead of
repeating.

## A/B interpretation

Arm A is the pre-change interface: each consumer must unfold/reconstruct
matrix action or register arithmetic locally, and the old task logs show that
the automated loop repeatedly treated the missing interface as proof search.
Arm B imports one named, compiled adapter and reduces each consumer to its
domain-specific column or clean-block theorem.

The observed improvement is therefore:

- reusable proof surface: zero named adapters to seven registered declarations;
- tested consumers: zero cross-interface tests to nine concrete examples or
  theorems in one integration module;
- controller behavior: repeated lower/capacity/tolerance work to a bounded
  prerequisite pass followed by stop when evidence is unchanged;
- trust visibility: ad hoc text scans to a comment/string-aware build gate.

This experiment does not establish lower token consumption on an independently
repeated model run.  A future model comparison must hold theorem text, model,
prompt budget, one-attempt stopping rule, and imported environment fixed and
report `task-only`, `LAD`, and `full-abeis` separately.
