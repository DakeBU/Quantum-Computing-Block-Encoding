# RobinMatrix: Lean4.33 compatibility, not completed block encoding

This maintenance package preserves the existing mathematical interfaces while
migrating the library from Lean4.29.1 to Lean4.33.0. The cited paper's scientific
scope in ASPBE is **block encoding**; this release does not claim its entire PDE
analysis formalized. All existing experimental classifications remain visible.

The independently checked patch changes five proof bodies and one local
elaboration-limit option, in seven diff hunks affecting six theorem commands.
All six public headers and every other source byte are preserved. Two added
`native_decide` proof sites remain explicitly disclosed; compilation does not
make them ordinary-three-axiom proofs or establish a clean transitive TCB.

The source-blind reconstruction and distinct independent comparison cover the
whole historical module, including private definitions, binders and structure

catalog. Compiled existence/axiom diagnostics are not semantic export reviews.
